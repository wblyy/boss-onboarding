# 回血 · 找工作

两个版本，同一套判断逻辑。

- `/` — 桌面端（左栏三个 tab、主区对话、右侧常驻栏）
- `/h5/` — 微信里打开的 H5，只有找工作

## H5 的公众号交接

扫描大约走到一半时弹二维码，引导关注服务号。关注之后，需要拍板的几件事
（选语气、补一个只有你知道的数字、要不要试一个够不到的岗）改成在公众号对话框里回，
页面上只留一行提示和角标。不关注也能用，所有交接落回页面底部弹层。

- 二维码为演示占位码，正式上线换成真实公众号码
- 决策只搬到账号侧，发送键仍然一次都不碰

## 设计约束

- 分数只用来排序，不是录用概率，页面上明说
- 匹配依据全部摊开：硬条件 / 经历对得上 / 信号，一条一行
- 「我替你按的发送」恒为 0，是承诺的实时证明
- 不替你发送，不批量投递，不保存登录态
